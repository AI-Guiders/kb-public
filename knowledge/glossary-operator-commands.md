# Глоссарий операторских команд и терминов среды (seed v1)

Оператор говорит образно и минимально; термины среды имеют точные значения, не выводимые из общих слов. Каждая запись: термин → точное значение → якорь-прецедент. Seed собран при OKF-миграции (ADR-026 M2); пополнять по касанию.

## Команды оператора

- **«Запиши это в KB»** — продолжить разговор письменно: зафиксировать знание из диалога как концепт канона (не «положить данные»): provenance, теги, правильная корзина. Личное — в `personal/` (contour u).
- **«Сделай фундаментальный проход по `<области>`»** — назвать область → агент идёт по **первоисточникам** (оригинальные научные работы, не статьи-пересказы) → evidence-карточки → статус/карта чтения мира. Уровни: **полный проход** (весь корпус области) vs **точечный запрос** (один вопрос). Ограничение: не грузить все kb одновременно. Прецеденты: `worlds/software-engineering-evidence/` (треки A–H, McConnell CC2), `worlds/philosophy-dao-chan/map-…-fundamental-pass.md`.
- **«По касанию»** — менять формат/структуру только при редактировании по другой причине; никаких отдельных массовых кампаний (прецедент: ADR-шифты продуктовых репо).
- **«Ребята, это с этим не связано»** — внешняя валидация transfer-гипотезы оператором; норматив — матрицы переноса (deny по умолчанию для локально-зависимого).
- **«Мясной / ИИшный новичок»** — человек / агент на онбординге KB; треки — `templates/newcomer/`.

## Термины среды

- **Contour (u/g/o)** — видимость знания: личное / групповое (общая копилка org: не публично, но всем агентам организации) / открытое. Механика: build policy (§8 ADR-026), поле `contour`.
- **Scope** — операционный контур проектов (`door-to-singularity`, `portal`, …); резолв workspace→scope — machine-карта `work/local/` (longest-prefix), единственный SSOT.
- **Hot / L0** — рабочая память сессии (`agent-notes.md`): контракты + scope-карточка; бюджеты см. Maintenance Contract.
- **Фундаментальный проход** — см. команды.
- **«Нет двойной формы»** — формат, получивший нативное поле, уходит из тела; SSOT один (ADR-026 §2).
- **Born-OKF** — концепт, созданный сразу с frontmatter по профилю ADR-026 (не мигрированный).
