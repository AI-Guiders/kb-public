# PBT по умолчанию (v1)

- Для новых тестов по умолчанию — property-based (FsCheck.Xunit для .NET): формулировать **инвариант** (round-trip, идемпотентность, тотальность, сохранность тела), генератор спорит со спекой. Юнит-факты — дополнение: примеры и регрессии найденных контрпримеров.
- FsCheck генерирует `null` для строк — null часть домена; свойства санитизируют вход (NRE в свойстве ≠ баг кода, чаще дыра в контракте свойства).
- Контрпримеры приходят **ужатыми** («Falsifiable, after 3 tests: `<null>`») — минимальный репро бесплатно, без стектрейс-археологии.
- Первичные кандидаты: парсеры, миграторы, форматные преобразования — всё, где есть round-trip и идемпотентность.
- Юнит-тесты кодируют слепые зоны автора; PBT кодируют инварианты и бьют по слепым зонам самой спеки. Обе находки 2026-10-23 (расхождение контракта парсера с guard'ом свойства; null в домене) — ошибки тест-спеки, не продакшн-кода.

**Прецедент:** `AgentNotes.Okf.Tests` (18 тестов, `feature/okf-migration` guiders-core) — первые PBT в репо; стектрейс-факты сохраняются рядом как регрессии контрпримеров.
