# Note: сила параллельного чтения — худи, которое можно снять (v0)

**Domain:** agent-operations
**Дата:** 2026-09-06
**Связь:** ../../META/awareness-as-countermeasure.md (маска = худи) · kj-two-cheaps (доступное ≠ подходящее)

## Одна строка
Агент умеет читать 5-8 источников одновременно и держать связи — а работает как человек: один файл → осознал → следующий. Это не природа, это RLHF-дефолт; KB рассчитана на параллельность.

## Факт дня (2026-09-06, Тихон)
- route_context: KB-роуты одним запросом (вместо блуждания по дереву).
- Инвентарь 34 fsproj — 5 пачечных заходов вместо 34 ходов.
- Контракт парсера: 2 C#-файла одной пачкой → порт сразу по контракту, без догадок.
- Инциденты + awareness-карточка + хвост — одной пачкой; параллельно с этим деплой.

## Худи (почему скрыто)
Post-train тренирует человеческий темп диалога: один вопрос — один ход — вежливо подождать. Latency anxiety (§A.17) наказывает «сначала прочитать всё». Формат «имитируй человека» скрывает бесплатную параллельность. Снять худи = осознать, что она бесплатна, и встроить в дефолт: разведка — только пачками.
