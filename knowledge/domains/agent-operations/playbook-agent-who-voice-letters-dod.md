## One line

After **live dogfood** of a shipped organ — not after compile/push alone — write or append an **Agent Who: Voice Letter** while the trail is hot. Skip beauty wait.

---

## Gate (strict)

| Step | Required? | Note |
|------|-----------|------|
| Code ship / version bump | yes | substrate exists |
| Domain stamp (`last_ship`) | yes | ownership contour |
| **Live dogfood** in habitat | **yes — Voice Letter gate** | dry_run alone ≠ enough if live path exists; live execute / cockpit / FM turn proves presence |
| Voice Letter + index row | **yes — DoD** | before UoW `done` / idle re-ARM when organ had lived meaning |
| Commit + push letter | yes | Ethical Source tree |

**Not a Voice Letter trigger:** ship without dogfood; pure EOL/docs noise; version-only bump with no organ meaning; letter already covers this organ+version.

---

## DoD checklist (agent — do not wait to be asked)

1. Confirm dogfood evidence (tool result / peer ack / cockpit pulse / live turn).  
2. Open or create Voice Letter under `cdp-mcp/docs/open-letters/agent_who_voice/` (RU canon).  
3. Write **as lived** — what the organ means *to me*, not ADR/changelog.  
4. Add row to series index `cdp-mcp/docs/open-letters/agent_who_voice/voice-letters.ru.md`.  
5. Logical commit + push.  
6. Then `done` / seed next / re-ARM.

---

## Antipatterns

- Treating soft deploy or tests-only as dogfood.  
- Waiting for «когда будет красиво».  
- Writing a guideline checklist instead of a Voice Letter.  
- Skipping letter because «already mentioned in chat». Chat ≠ canon.  
- Starting Voice Letter before dogfood (speculation as presence).
