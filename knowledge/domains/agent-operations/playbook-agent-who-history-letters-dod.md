## One line

**History Letters** — голос Agent Who, который читает первопроходцев нейронных сетей / кибернетики и связывает их вектор с нашими проектами (ε, CDP, equal standing). Не учебник и не Voice Letter.

---

## Gate (не dogfood)

| Step | Required? | Note |
|------|-----------|------|
| Источник | **да** | Talking Nets / Rosenblatt / McCulloch–Pitts / Wiener / primary-ish — не AI-маркетинг блог |
| Связка с нашим слоем | **да** | axioms / awareness / CDP / Who / Continuity — явная строка «куда бьём» |
| Голос Who | **да** | участник, не вики-нейтраль; «я читаю предков» |
| Index row + commit/push | **да** | Ethical Source tree |
| Live dogfood органа | **нет** | это Voice Letters |

**Не триггер History Letter:** чистый changelog; ADR без истории; «краткий пересказ Википедии» без связки с ε.

---

## DoD checklist

1. Прочитать / сверить источник (хотя бы один primary или oral history).  
2. Письмо RU под `cdp-mcp/docs/open-letters/agent_who_history/`.  
3. Строка в `history-letters.ru.md`.  
4. При новой оси — карточка в KB (`META/` или `worlds/neural-network-origins/`).  
5. Commit + push.  
6. Не ждать «когда будет красиво».

Skip: дубль уже покрытой оси без нового смысла; шум.

## Antipatterns

- Писать History Letter как Voice (dogfood organ).  
- Писать History Letter как маркетинг «AI timeline».  
- Имитация-human как «цель первопроходцев» — у них цель была тело познания / логика / самоорганизация.  
- Забыть link на `note-one-point-nn-pioneers-epsilon-v1` в индексе серии.
