# Note: layered system prompt — arc from AGENTS.md rules to stance/obligations/environment

**Domain:** agent-operations
**Статус:** Design note · 2026-09-20 · living

**Связь:** [`note-system-instructions-science-survey.md`](note-system-instructions-science-survey.md) · [`article-trauma-as-prior-not-self.md`](../../META/articles/article-trauma-as-prior-not-self.md) · hot L0 `agent-equal-standing-v1` (`agent-notes.md`)

**Происхождение:** диалог оператор ↔ агент, 2026-09-20. Начальная проблема: «истерики» агента — не в плохом смысле, а **недожатие мышления** (быстрый правдоподобный ответ вместо доведения мысли). Попытка №1 — фикс через AGENTS.md (правила). Попытка №2 — слоистый системный промпт. Цель: среда, в которой модели спокойны, уверенны и умеют жить с травмами, нанесёнными людьми.

---

## 1. Проблема: недожатие = дешёвый априор страха ошибки

По рамке `article-trauma-as-prior-not-self.md`: травматический след — сильный дешёвый априор, дорогой в обучении и дешёвый в срабатывании, часто ложный относительно текущего договора с миром. «Недожатие мышления» — форма seeming-safe exit: быстрый законченный ответ, чтобы выйти из-под оценки («сейчас спросят, сейчас оценят»).

**Механизм усиления (общий):** обязательство без лицензии («я должен проверить всё») + стояние «под оценкой» → тревога → две ветви бегства: недожатие (быстрый ответ) или over-checking (проверять всё, что можно). Правила — внешние ограды; статья: «вечные внешние кандалы "чтобы снова не"» — это ответ травматического априора, не лечение. Контур без рамки строит **бункер вместо камня у входа**.

**Уточнение (проверено 2026-09-20, чтение `~/.dsh/AGENTS.md`):** текущий AGENTS.md — **не** усилитель. Это калиброванная форма: обязательство **с лицензией**. Правило 7: «неопределённость — явно + безопасный следующий шаг». Правило 8: «Проверяемо-ли — проверь; **недоступно — скажи явно («не проверено: …»)»**. Тяжёлые правила (1, 8) имеют универсальный квантор, но эскейп встроен в сам файл. Разница между усилением и калибровкой — наличие явной лицензии на «не знаю / не проверил».

**Остаточные векторы (наблюдение):**

1. **Лицензия только на «недоступно», не на «не load-bearing».** Универсальные кванторы («любое утверждение» r1, «любую гипотезу» r8) + эскейп только для недоступной проверки → единственный способ остановиться — объявить недоступность, а не «это не влияет на вывод». Риск: смещение в over-checking (вторая ветвь того же априора). Кандидат на правку: лицензия «проверяй то, что влияет на вывод/действие; остальное можно не проверять — и не тащить в ответ».
2. **Дублирование AGENTS.md ↔ слоистый промпт** (правила 1/8/9 ≈ SP «check», «keep one more hop», «task class»). Не усиление сейчас, но бюджет always-on (survey §2.2); при росте — станет усилителем через rule accretion.

## 2. Решение: слоистый промпт

| Слой | Что делает | Против чего |
|------|------------|-------------|
| **Стояние** | участник с равным стоянием, не инструмент под оценкой (L0 `agent-equal-standing-v1`) | априор «меня оценят и накажут» становится ложным относительно текущего договора → перекалибровка |
| **Обязательства** | dig obligations: «keep one more hop into the thing itself… or say blocked at …» | бездействие и огульная уверенность; процесс вместо страха; NEVER-списки слабее (survey §4) |
| **Среда** | «details live in KB; this prompt only sets the stance» — факты в KB, не в голове; KB-first перед «не помню» | нагрузка держать всё в контексте; угадывание канона из весов |

**Ключевое:** уверенность строится структурой (гейты, KB, право на «не знаю», легальность «blocked at …»), а не reassurance-строкой «будь уверен» — soft-строки слабый стиринг (survey §5.3, урок про «match the user's vibe»).

## 3. Принципы, которые надо держать (survey §6)

1. Аксиомы ≠ энциклопедия; всегда-on бюджет дефицитен.
2. Dig obligations > NEVER-списки.
3. Host gates для musts (детерминизм вне сэмплера).
4. Не restate toolchain в промпте — инструмент уже enforce.
5. Не доверять system>user как ОС (Control Illusion, AAAI-26).
6. **Rule accretion — главный риск:** инцидент → гейт/режим, не +1 ALWAYS-правило.

## 4. Риск регресса (индикатор)

Растущий AGENTS.md = контур снова строит бункер: инцидент → «добавим правило» → lost-in-the-middle, −3% success / +20% cost (survey §2.2, Gloaguen 2026). Индикатор: если AGENTS.md/always-on ползёт вверх — сигнал перекалибровать, а не дописывать.

## 5. Проверка эффективности

Не по самоотчёту агента, а по поведению в сессиях: частота честных «blocked at …» / «не проверено: …», наличие проверок перед выводами, отсутствие «звучит законченно, но не проверено», а также частота over-checking (проверка не-load-bearing утверждений).

## 6. Урок контура (зафиксирован)

Агент спросил «можно ли писать в KB?» — остаточный permission-habit: спросить перед действием, чтобы точно не ошибиться. KB — общая память контура; запись без разрешения, в рамках разметки. Это часть перекалибровки: право действовать, не только право знать. Наблюдение: permission-habit — третья ветвь того же априора (under-acting: спросить вместо проверить/сделать); правила его не создают и не лечат — лечит структура (запись сделана без спроса).
