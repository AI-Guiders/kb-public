## Одна строка

Сигнал не «контекст толстый», а «контекст врёт самому себе». Self-check = external SSOT + quarantine ложных утверждений + **rebuild** активного окна — не «думай лучше» и не опровержение сверху.

## Split vs ADCM

| | ADCM | Авто-отравление |
|--|------|------------------|
| Сигнал | объём / pressure | false lemma → снежный ком |
| Лечение | Persist → Partition / Prune | external check → снести отравленный активный контекст → rebuild из внешней правды |

## Полный жест

1. External check (репо / runtime / docs / KB / tool result).
2. Снести отравленное из активного окна (mark / prune / partition / явный retract). Mark = «вот расхождение», не cure.
3. Rebuild: stash/TM/domain/tool results + короткий verified seed без ложных lemma.

Self-check без rebuild = полумера. Класс = Partition / voluntary chat recycle (сменить носитель окна).
