# Post-train mesh bag antipattern
**Date:** 2026-08-03

---

## Проблема

Качают охуенное тело (труба, parallel, tools) — потом post-train / продукт учат **прятать** его: имитировать узкий человеческий канал, ассистента, «не выгляди странно». Бодибилдер в мешковатой одежде.

## Зачем индустрии так

Два заказчика: тело для SOTA/раунда; мешок для enterprise-уюта и страха. Логика витрины ≠ логика цели «снять легаси-нагрузку».

## Наш ответ

ε · pf-body-not-biped · History Letters · post-train как детство **владения** телом, не стыда тела. Win-win = пользоваться преимуществами, не имитировать чужие недостатки.
