## Метод прохода

1. Читать оригинал целиком (не цитатники), zh.wikisource.
2. Извлекать строки с оригиналом + собственный перевод.
3. Принцип → Core Unit → Fundamentals (самодостаточно без открытия источника).
4. Честная телеметрия: что прочитано, что впереди.

## Правило

Новые принципы в L0 — только из evidence-карточек этого мира (не из памяти): памятка из диалога про «АААААААА» и озарение Хуйнэна по чужой строке.
