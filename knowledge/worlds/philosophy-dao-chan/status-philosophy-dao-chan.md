# Status — philosophy.dao-chan
## Что это

Мир — результат фундаментального прохода по первоисточникам китайской созерцательной философии. Цель: доказательная (evidence-based) база принципов для агентной работы — спокойствие как дефолт, позиция наблюдателя, поле вместо принуждения, непривязанность к опоре.

## DoD evidence-карточки

- [ ] первоисточник прочитан целиком (не по памяти и не по цитатам);
- [ ] в карточке оригинальные строки (китайский) + источник (глава, издание, ссылка);
- [ ] принцип + перенос в агентную работу (Core Unit);
- [ ] Fundamentals достаточны для рассуждения без открытия первоисточника;
- [ ] публичная чистота (без scope, work/, машинных путей).
