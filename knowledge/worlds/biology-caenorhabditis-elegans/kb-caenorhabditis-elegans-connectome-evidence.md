## Fundamentals

### 1) Сети (из ISCI)
- CeH0c (корректированный White): 280 узлов / 2 895 рёбер; CeH2c/CeH3c (Witvliet 2020): 180/1 669/1 633; CeMc (самец): 358/3 195; CeMe (электрические): 317; CePc (глотка): 20; стадии L1–L3: 161–174 узла; D. melanogaster 1-я личинка — включена (пара сравнения!).
- Анализ: undirected/unweighted, крупнейший компонент, только химические синапсы (для «с»-сетей).

### 2) Стереотипность — на уровне СТЕПЕНИ, не связей
- **Degree — инвариант класса**: сильная L/R корреляция (identity line); «consistent and innate property of each neuron class, shared by its members»; небольшие отклонения — стохастические (не фиксированы).
- **Композиция (партнёры) — асимметрична и частично стохастична**: ~24% всех хим. синапсов во всех 3 сетях; **парные (L/R-симметричные) — 39% консистентны; непарные — ~2.5%** → непарные — стохастические/опыт-зависимые; парные — предопределённые.

### 3) Redundancy vs Reachability (баланс)
- Симметрия → Redundancy (дублирование путей — надёжность); асимметрия → Reachability (больше классов достижимо — гибкость).
- Коннектом: fu ≈ 0.36–0.53 (смещение к симметрии → Redundancy); парные синапсы → ~65% Redundancy; непарные → ~35%.
- Redundancy — узкий диапазон между коннектомами; Reachability/асимметрия — варьируют.
- 53.6% классов — L/R взаимосвязаны (≥1 синапс).

### 4) Фибрации/симметрии (PLOS)
- **Фибрация = изоморфные входные деревья** (идентичная входная история) → кластеры; **орбиты** (автоморфизмы) — групповые симметрии.
- Локомоционная сеть (forward/backward): моторные нейроны — **самый похожий класс** (scRNA-seq!); feedforward возбуждение от командных интернейронов → **высокая синхронизация моторного выхода**.
- **Ручные ремонты** (в пределах 25% вариации рёбер!) — чтобы выявить симметрии («без модификации каждый нейрон уникален» — сырой коннектом менее симметричен!).
- Симуляции: фибры/орбиты предсказывают синхронизацию кластеров (подтверждено ODE-моделями; при больших стимулах — нестабильности).

### 5) Для CASA
- **Стереотипная степень + стохастическая композиция** = «каталог сильных (консистентных) рёбер + вариация слабых» — инвариант (совпадает с дрозофилой: 53% сильные cross-dataset; мышь: like-to-like).
- **Кластеры по входной истории (фибрации)** = «одинаковые входы → одинаковая динамика (синхронизация)» — для CASA: группировка по входным деревьям (не по типу!).
- **Баланс Redundancy/Reachability** — дизайн-принцип (надёжность vs гибкость).
- **Моторный выход — однородный класс** — подтверждение стереотипности эффекторов (воронка).
