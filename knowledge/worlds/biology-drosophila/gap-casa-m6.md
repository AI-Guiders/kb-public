## 1. Что такое CASA (кратко, для сравнения)

- **Субстрат**: клеточный автомат, дискретная сетка, **локальное правило обновления** («однородный геном на всё поле», ~8k параметров ядра — Distill NCA), без тяжёлого transformer-контроллера
- **Компоненты v0/v1**: state tensor (каналы: sensory/memory/control/latent), I/O ports (read/write bands), policy extraction head (зоны → действие), telemetry plane (паттерны/мотивы/энтропия)
- **Цикл**: observe → update → act
- **Три цели**: (1) CA как субстрат + локальность (выигрыш на инференсе), (2) AiNet-обмен через TDA-дескрипторы + KB-фрагменты в поле, (3) имитационное обучение с правом на ошибку (IOP: намерение→дельта→верификация→уточнение; damage-восстановление; read/write bands как «учитель»; отложенный verify)
- **Память (prism)**: L0 hot / L1 operational / L2 episodic (hippo) / L3 router; **sleep_promote** (консолидация), compaction
- **Roadmap**: v0 субстрат → v1 смысл в поле → v2 агентный контур → v3 AiNet

## 2. Сопоставление: законы мира ↔ CASA

| Закон (биология) | Биология (что известно) | CASA (что есть) | Вердикт |
|---|---|---|---|

| **З2: модульность + супервизоры** (13 кластеров; MB→140, CX→20; optic 97.7% intrinsic; 17 поведенческих AN/DN-кластеров) | Модули + координаторы, НЕ центральный контроллер | Однородное поле + каналы; **нет модулей/кластеров**, нет супервизора; control channels — ближайший аналог | **РАСХОЖДЕНИЕ** (частично: каналы) |

| **З4: обучение = отдельный модуль, локальная пластичность, консолидация** | MB (KC из MBp, DAN из CREa — учитель отдельно!), LTP/LTD по ботонам, Chd1 (транскрипц.), сон-консолидация (глия, Tequila) | **СИЛЬНОЕ СООТВЕТСТВИЕ**: read/write bands = внешний учитель пишет в зону; damage-восстановление = гомеостаз; отложенный verify + **sleep_promote** = консолидация; prism_hippo = эпизодическая память | **СООТВЕТСТВУЕТ** (закон 4 — реализован по духу!) |
| **З5: генетическая детерминация (два кода)** | Пол (sxl→tra→dsx/fru) + время (birth-order, Nature 2026); линии→типы→модули | **«Однородный геном на всё поле»** = один код → все клетки! Каналы/зоны = «типы» из одного ядра | **ЧАСТИЧНО** (гомология генома есть; двух кодов нет: нет аналога «времени рождения») |
| **З6: инварианты vs пластичность** | Поток/модули/НТ консервативны; MB/CX/репертуары варьируют; половые цепи: constraints + evolvability | Freeze vs adaptive local rules (ablation) — признание; архитектура фиксирована, правила адаптивны | **ЧАСТИЧНО** (freeze-вариант есть) |

## 3. GAP-список (если цель — биологически-правдоподобный агент)

**Сильные стороны CASA (биология подтверждает дизайн):**
1. **Локальность** — биология: всё на локальных связях (81% intrinsic), без глобального центра — CASA совпадает
2. **Отдельный «учитель»** (read/write bands ↔ DAN из CREa пишет в MB) — CASA уже так делает
3. **Консолидация** (отложенный verify + sleep_promote ↔ сон-консолидация) — совпадает
4. **Однородный геном** — сильная гомология с биологией (один код → все клетки)
5. **Восстановление после damage** — гомеостаз (биология: глия, Chd1)

**Что отсутствует (кандидаты на добавление/эксперимент):**
1. **Bottleneck выхода** — самое значимое расхождение: биология сжимает всё в ~0.5% эффекторов через 3 хопа. Для CASA: **гипотеза — добавить «выходной вентиль»** (малый набор зон/клеток, которые читают поле и выдают действие; иерархию сжатия). Это может дать устойчивость к шуму (мало что может «испортить» выход) и интерпретируемость (наблюдать вентиль)
2. **Модули/супервизоры** — биология: optic_lobe изолирован (97.7%), MB/CX — супервизоры. Для CASA: **гипотеза — специализация зон** (сенсорная зона изолирована; «координатор»-зона, дающая указания, не контролирующая всё) — может улучшить стабильность и интерпретируемость
3. **Gain-каналы (модуляция)** — биология: ~9.5% нейронов — тонические усилители. Для CASA: **гипотеза — глобальные gain-каналы** (масштабирование активности зон) — дешёвый способ управления поведением без переобучения
4. **Два кода** — у CASA есть «геном» (ядро), но нет «времени рождения» (temporal identity). Для CASA: **гипотеза — фазовое правило** (клетки получают разные функции по «возрасту»/позиции — как birth-order) — возможно, улучшит разнообразие ролей без роста параметров

**Что НЕ нужно (биология не требует):**
- Генетический половой код (sxl→tra) — для агента нет пола; это не инвариант
- 188k нейронов — CASA-поле может быть малым (8k параметров ядра уже достаточно)

## 4. Рекомендации (приоритеты, как гипотезы для CASA-экспериментов)

1. **P1 — bottleneck выхода**: эксперимент «выходной вентиль» (v2 агентный контур) — прямо проверяемо, потенциально даёт устойчивость + интерпретируемость. **Это главный перенос из синтеза.**
2. **P2 — супервизорная зона**: эксперимент «координатор» — один/несколько «управляющих» зон с указаниями (не контролем) — проверка стабильности и управляемости.
3. **P3 — gain-каналы**: эксперимент «модуляция» — глобальные масштабирующие каналы как дешёвое управление (гипотеза: лучше, чем переобучение на каждую задачу).
4. **P4 — фазовое разнообразие**: гипотеза из birth-order — клетки поля с разной «фазой» (время инициализации/обучения) → разные роли из одного ядра.

## 5. Ограничения отчёта (честно)

- **Сравнение концептуальное**, не количественное: биология — реальная система (188 508 нейронов, данные), CASA — spec/черновик v0-v3 (реализация частично, nca-lab)
- CASA **не обязана** повторять муху: биология — источник **гипотез**, не требований. Законы 1–6 — инварианты *наблюдённой* биологии, не «правильные» архитектуры
- Нет измерений CASA-агента (stability/robustness) для сравнения — отчёт только по дизайну
- Половая детерминация, эволюция песни и т.п. — для CASA неприменимы как механизмы (могут дать метафоры, не требования)

## Правка: актуальный дизайн CASA (проверено по коду и design/, 2026-09-19)

### Уровни реализации (что реально есть)
1. **nca-lab (v0, калибровка субстрата)**: классическая решётка Distill — 16 каналов, Conv2d 1×1 (perception: x + sobel), UpdateRule 48→128→16, alive_mask по альфе, damage-круги («раны»), grow_from_seed. Это «вырастить картинку» — НЕ агентная структура
2. **layout.v1.json (INTERIM, замещён)**: 64×64 решётка с **зонами-регионами** (B0 графемы / B1 слоги / B2 слова / B3 фразы; sn_router SN-analog; cen_planner CEN-analog) и **портами** (p1_dmn_to_sn digest, p3_cen_to_dmn) — зональная решётка, но всё ещё решётка
3. **zone-prism-map.v1.json + prisms/memory/stack.json (schema v3, актуальный)**: **УЖЕ НЕ ОДНА РЕШЁТКА**:
   - **Множество латитсов** (отдельные NCA-сети!) по **z_levels 0–3**: alphabet-ru/en (z0), syllables-ru (z1), lexicon-ru-{00..63} — **64 шарда** (z2), morph-role-ru (z2), phrases (z3)
   - **z_bridges** (вертикальные мосты L0→L1→L2→L3)
   - **Зоны**: memory_zone (episodic: prism_hippo + dialogue_ring/journal + H0–H3 латитс-паттерны; semantic: prism_memory + wm_prism + домены lang/math/vis; procedural: intent_prism + nca/*/model.pt; priming: decay 6 тиков) + intelligence zones (linguistic/logical/spatial/social — клиенты, не владельцы памяти)
   - **Сон-консолидация**: sleep_hook run_sleep, hippo_to_memory_bridges h_bridge_* (multi-cylinder-memory)
   - **Мутабельность**: иммутабельные латитсы (alphabet-*, syllables-ru, morph-role-*) vs мутабельные (эпизодические); **write_gate: genetic.promote_canon**
   - Каждый латитс — свой NCA-профиль (sss) + nca/memory/lexicon/{shard}/ + ltm/memory/{layer}/{lattice}.ltm

### Главный вывод (для ответа на вопрос «как хранит»)
- CASA **уже отошла от одной решётки**: иерархия латитсов + зоны + призмы + консолидация + гейты — структурно ближе к биологии, чем spec v0/v1
- **Остаются расхождения**: (а) каждый латитс — всё ещё плотная NCA-решётка (нет разреженного комбинаторного кода); (б) нет «адреса = история рождения»; (в) нет зональных учителей-подкреплений (DAN-аналог) — есть внешние bands/гейты
- **Предложение P5 уточнено**: не «заменить решётку», а (1) добавить разреженность/комбинаторный код внутри латитсов, (2) идентичность-историю, (3) зональных учителей — как эксперименты поверх v3

## Правка 3 (2026-09-19, раунд «контекстный гейт/интуиция»): cLTM — context-gated memory

Из полных текстов (Nat Commun 2019 cLTM + eLife 2019 Dolan/Frechter — LH) добавлено:

**Факты:**
- **cLTM (контекстно-зависимая LTM)**: retrieval требует ВСЕ контекстные условия (свет+температура+решётка) — **ANY mismatch → PI=0** (Nat Commun 2019); формируется без синтеза белка (CXM/RICIN/dCREB2b), вне MB (OK107/C772), DA-зависимая (TH/dDA1), длится ≥14 дней, холодостойкая; retrieval требует: AMMC (механо)+зрение+вкус+обоняние → **LH** (iPNs/ePNs/LH-нейроны; MB-V2 — диспенсабелен).
- **LH — мультимодальная конвергенция** (Dolan 2019): LHIN из механо/слуха (WED-PN1–6), зрения (LO-PN1–2), вкуса (GNG-PN1), VNC (VNC-PN1), + термо; **часть LH-нейронов не отвечает на запахи** (Frechter 2019); **LH→DAN** (PAM/PPL1) — врождённый сигнал в обучающий контур; **валентность** в LH (конвергенция аверсивных/аттрактивных гломерул; оптогенетика — подход/избегание); LHON→SLP/SMP, PV5k1→CX.
- **Механизм «проверки» условий — НЕ установлен** (порог vs AND vs веса); структурная база (мультимодальные входы) подтверждена; синаптический уровень (BANC) — не анализирован.

**Инженерная идея для CASA (P8 — context-gated memory / «интуиция»):**
- **«Спящее знание»**: знания (L0–L3 prism/карточки) хранятся **с условиями доступа** (state-вектор: task × env × state × history) — метаданные; **активация по совпадению всех условий** (детектор на I/O bands + telemetry — датчики уже есть), иначе — не загружается (освобождение контекста!).
- **Гейт вместо сходства**: строгий AND (как биология: любой mismatch → zero) или порог с весами (настраиваемый) — **защита от интерференции** (противоположность RAG-по-сходству).
- **Валентность**: при активации — пометка значимости (важно/опасно/хорошо) — «чувство правильности» (соматический маркер-аналог; LH-валентность + LH→DAN).
- **Это и есть «интуиция»-механизм**: знание всплывает «в нужном месте в нужное время» без поиска; лежит — не мешает.

**Границы (честно):** гейт — про retrieval (не хранение); это компонент интуиции (не весь механизм); AND у биологии может быть порогом; cLTM — одна работа (структурная база — 2 независимые работы: Dolan+Frechter); BANC-анализ — отложен (сеть).

**Приоритет: P8 — новый кандидат (высокий интерес, изучение) — сродни P6 (арбитраж) + P7 (аттракторы) + prism-память (L0–L3 + sleep_promote).**

## Правка 4 (2026-09-19, раунд «инстинкты vs исполнительный контроль»): «доска с приорами» — принцип реорганизации

**Проверено (полные тексты):** PMC7145822 (наивная валентность = мягкий приор), PMC13196396 (courtship suppression — DA-зависимое, стресс/опыт), SMP353/SPIN (арбитраж + GluClα-шунт), FB-бамп (удержание намерения 5–10 с).

### Ключевой вывод: «инстинктов» нет ни у кого (даже у мухи)
- **Жёсткое — только архитектура**: каталог (типы/связи/NT/воронка), моторные примитивы (LBL40/LUL130), мотивации/гомеостаз (state). Это НЕ поведение.
- **Мягкое — всё поведение**: наивная валентность = **приор** (PMC7145822: отключается голодом, гейтируется концентрацией, развивается 80 с, переписывается обучением; MBON > uPN; learned > innate).
- **Модель: «доска с приорами»** — архитектура + мягкие мотивационные приоры + обучение/контекст/состояние. Не «инстинкты», не «чистая доска».

### Исполнительный контроль (вместо «инстинктов»/«воли») — есть у мухи функционально:
1. **Удержание намерения**: FB-бамп (goal) персистентный 5–10 с; 3 состояния (baseline/goal/search); оптимум к статистике среды → **аттрактор цели** (P7!).
2. **Подавление альтернатив**: арбитраж (SMP353: социальное > foraging — ингибирование конкурирующей мотивации = P6!); **GluClα-шунт (мультипликативное отключение)**; APL-ингибирование (MB sparse) → **тормозной контроль**.
3. **Обновление по контексту**: evidence integration (P7), cLTM-гейт (P8: AND-условия), DA-гейтированное обучение (TD) → **контекстное обновление**.
4. **Обученное подавление врождённого**: courtship suppression (DA, стресс/опыт) — врождённое подавляется опытом → **пластичность приоров** (не «воля», а обучение).

### Для CASA (объединение P6+P7+P8 в один блок «исполнительный контроль»):
- **НЕ проектировать «инстинкты»** (жёсткие стимул→ответ) — их нет даже у мухи.
- **Проектировать**: (а) жёсткая архитектура (каналы/примитивы/воронка/каталог); (б) **мягкие приоры валентности** (стартовые смещения, переписываемые обучением); (в) **исполнительный контроль** = удержание намерения (аттрактор) + подавление альтернатив (арбитраж/торможение) + контекстное обновление (гейт/evidence); (г) state-модуляция (голод→приоритеты); (д) обучение (TD + efference + 2 трека).
- **Терминология**: «врождённая валентность» (не «инстинкты»); «приоры» (не «программы»).

**Приоритет: P6/P7/P8 → единый блок «исполнительный контроль» (высокий, основа реорганизации).**

## Правка 10 (2026-09-19): «КАК МУХА СДЕЛАНА vs КАК МЫ СДЕЛАЛИ» — полное сравнение

### ГЛАВНЫЙ ВЫВОД (ответ на «NCA должны специализироваться»):
