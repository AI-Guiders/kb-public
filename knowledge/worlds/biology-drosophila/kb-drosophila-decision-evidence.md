## Core Unit
- context:
  - как муха принимает решения в навигации: интеграция обонятельных свидетельств, поддержание цели (goal direction) после потери запаха — рабочая память.
- signal:
  - вопрос «как муха решает, куда идти», «есть ли рабочая память», «как интегрируется шумный сигнал».
- action:
  - использовать: **VT062617 (h∆K21 FB local)**: локальный бамп активности, включается запахом, **остаётся, пока муха держит goal heading** (по ветру; вращение ветра НЕ вращает бамп — goal в рамке ветра!); **интеграция**: ramping при повторных импульсах (широкий фильтр — длинное окно); **52G12** (другие FB local): транзиентные (узкий фильтр), корреляция с поворотами — **динамика специфична подмножеству FB**; **причинность**: GtACR1-ингибирование → ↓upwind после потери запаха (не нужна для выбора начальной траектории, нужна для поддержания); свободно ходящие: 4+ импульса → насыщение, персистентность **5–10 с**; **оптимальность**: теория — интегрировать окно ≈ средняя длительность пробелов в шлейфе; измеренная персистентность **совпадает с оптимальной** (модель 3 состояний: baseline/goal/search, τp; 95% CI); **механизм**: h∆K21↔PFG рекуррентность (follow-up — критична для бампа); **сравнение**: PFC-персистентная активность (обезьяны), ramping (кора) — здесь в генетически идентифицированных нейронах + полный коннектом; **личинки**: без полного CX — egocentric; взрослые — allocentric (FB = GOAL, не только heading!).
- outcome:
  - FB кодирует **цель** (не только направление) через персистентный бамп; интеграция шумного запаха — ramping (evidence accumulation); время памяти — оптимально к статистике среды; механизм — рекуррентность (аттрактор).
- lesson:
  - **решения = интеграция свидетельств (ramping) + аттракторная память (персистентный бамп) + 3 состояния (baseline/goal/search) + оптимум к статистике среды** — для CASA: это конкретная реализация «evidence accumulation + working memory», с измеримой оптимальностью.

## Fundamentals (самодостаточный опорный слой)

### 1) Goal-репрезентация (FB)
- VT062617 (h∆K21): бамп в FB-колонках; включается запахом; сохраняется при поддержании goal (по ветру); не вращается с ветром — allocentric goal в ветровой рамке.
- Отличие от heading (EPG/EB): FB = цель, CX = направление — два разных представления!

### 2) Интеграция и персистентность
- VT062617: широкий фильтр (длительное окно) — интеграция; 52G12: узкий (транзиент), корреляция с поворотами — специфичность.
- Причинность: GtACR1 → ↓upwind после odor OFF (но не в начале); свободно ходящие: персистентность 5–10 с, насыщение ~4 импульса.

### 3) Оптимальность и модель
- 3 состояния (baseline/goal/search); переход goal→search — вероятностный (τp); измеренная персистентность ≈ оптимальная для граничного слоя (2 теоретических исследования: интегрировать по средней длительности пробелов).
- Модель локомоции: 5 DN-подобных единиц (U1-U5, матрица M) — forward/angular скорости.

### 4) Механизм и сравнение
- h∆K21 ↔ PFG — рекуррентные связи (коннектом eLife 2021); follow-up: рекуррентность критична для персистентного бампа.
- Аналоги: PFC (персистентная активность, обезьяны), корковый ramping — у дрозофилы генетически идентифицировано + полный коннектом.
