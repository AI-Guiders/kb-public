## Цель

Сравнить дрозофилу (полный референс) с другими доступными коннектомами, чтобы:
1. Проверить инварианты (законы 1–6) на других масштабах/филогениях.
2. Найти «что меняется между организмами» — для расширения CASA (наслоение).
3. Честно зафиксировать границы сравнения (фрагменты ≠ полные).

## Собранные данные (ключевое)

### Личинка дрозофилы (Science 2023, Winding et al.)
- 3 016 нейронов / ~548k синапсов; >99% реконструированы; 75% синапсов связаны.
- **4 типа соединений**: a-d 66.6%, **a-a 25.8%** (аксонная модуляция у 71.8%!), d-d 5.8%, d-a 1.8% — не только аксодендритные.
- 93 типа (по коннективности); хабы: 506 a-d; **73% in-out хабов — у MB**.
- **Рекуррентность обучения**: DAN 57%, MB-FBN 51%, MBON 45%, CN 42%; KC 0.1%.
- **Efference copy**: 37% DNsVNC / 66% DNsSEZ → мозг (копии моторных команд) — DANs получают обратную связь от моторных команд.

### Мышь MICrONS (Nature 2025 ×2)
- 1 200×1 100×500 µm³ кора (V1+AL/LM/RL), слои 2–6; один мыш, GCaMP6s; 14 сканов.
- **115 372 функц. единиц → ~75 909 уникальных нейронов**; RNN digital twin; 2 934 фидуциала (3.8 µm); 19 181 ROI → 15 439 EM.
- >900k синаптических связей (proofread); типы: морфология+коннективность.
- **Wiring rule (like-to-like)**: аксонный уровень — Ld ↑ с функциональным сходством (и RF); **синаптический — ТОЛЬКО feature similarity (Hebbian!)**, RF-расстояние не влияет; multiplicity/cleft ↑ с similarity.
- **Прямое сравнение с дрозофилой (из статьи)**: у дрозофилы 20% EM-типов были новыми; **стереотипия: коннектом одной мухи применим к другим; у мыши — гетерогенность** (коннектом одной мыши не переносится).

## Первые инженерные выводы (для сравнения)

1. **«Подобное соединяется с подобным»** — общий принцип сборки (мышь: feature similarity; дрозофила: стереотипный каталог + сильные рёбра по типу). Разница: у мыши правило реализуется функционально (Hebbian-подобно), у дрозофилы — генетически (каталог).
2. **Efference copy** (личинка) — действие → учитель: аналог IOP-петли CASA («намерение→дельта») — сильный материал.
3. **Ремоделирование** (личинка↔имаго) — метаморфоз перестраивает мозг: как «одна программа» порождает два мозга.
4. **Масштаб**: 302 (C. elegans) → 3 016 (личинка) → 160k (имаго) → 75 909 (мышь, кора) — каталог/стереотипия удерживается у насекомых, падает у млекопитающих (гетерогенность).

### Инварианты (проверка)

1. **Like-to-like («подобное соединяется с подобным») — ПОДТВЕРЖДЁН на двух филогениях**: мышь — функционально (Hebbian, feature similarity — синаптический уровень!); дрозофила — генетически (каталог: линия→NT→сильные связи = «подобные» по типу). **Механизм разный, цель одна** → инвариант высокого уровня.
2. **Действие → учитель (efference copy) — ПОДТВЕРЖДЁН (личинка: 37% DNsVNC→мозг; дрозофила: реафферентные петли, DANs от моторных команд)** → аналог IOP CASA.
3. **Воронка выхода — подтверждена у дрозофилы (0.5% эффекторов); у личинки — есть моторные DNs; у мыши/C. elegans — НЕ измерено (открыто)** → вероятный инвариант, но проверка неполная.
4. **Стереотипия падает с масштабом/филогенией**: насекомые — стереотип (переносимый коннектом!); млекопитающие — гетерогенность (индивидуальный коннектом) → **«каталог» — не универсальный механизм; у млекопитающих — статистический/функциональный** (для CASA: каталог+вариация; у нас уже «типы ≠ атомы»).
5. **Модульность/хабы — везде, где есть нейропили** (личинка MB-хабы; дрозофила 13 сетей; мышь — колонки) → модульность — инвариант (но реализация разная).
6. **Ремоделирование (метаморфоз) — уникальный кейс дрозофилы** → «версионирование» — не универсально.
7. **TD-подобное обучение + контекстный гейт — подтверждены только у дрозофилы** (мышь — Hebbian; C. elegans — поведенческое; человек — нет) → это НЕ универсальные инварианты (возможно, масштаб-зависимые или неисследованные).

### Выводы (для CASA)

- **Дрозофила — единственный полный+богатый референс**: каталог+сильные рёбра+модули+bottleneck+TD-обучение+аттракторы+контекстный гейт+SPIN-валентность — всё в одном.
- **Мышь MICrONS — ключевой контрпример**: like-to-like = Hebbian (функциональное сходство!) — для CASA: **связность по сходству представлений** (не по каталогу) — наш вариант «self-organizing» подтверждается.
- **C. elegans — минимальная проверка инвариантов** (стереотипия, модульность-нет, обучение-да) — НО: классика не прочитана (граница; Cook 2019 — аннотация только).
- **Человек — только масштаб** (1/1.2M, без функции) — не информативен для механики.
- **Инварианты для CASA (сильные)**: like-to-like (сходство→связь), efference copy (действие→учитель), воронка выхода (мало эффекторов), модульность (нейропили), TD-обучение+контекстный гейт (дрозофила — уникально богатый набор).

## C. elegans — закрыто (2026-09-19, OA-анализы прочитаны)

**Источники:** PMC11388161 (iScience 2024, асимметрия/Redundancy/Reachability) + PMC11006206 (PLoS One 2024, фибрации/синхронизация) — полные тексты. Классика (White 1986/Cook 2019) — OA:N (не прочитана; данные — через эти анализы).

**Данные (заменяют «?» в таблице):**
- **Стереотипность**: degree — инвариант класса (L/R корреляция; «innate property of each neuron class»); **композиция партнёров — асимметрична**: ~24% синапсов во всех 3 сетях; **парные — 39% консистентны, непарные — ~2.5%** → парные предопределены, непарные — стохастика → **подтверждение «сильные рёбра = программа, слабые = шум»** (совпадает с дрозофилой 53% и мышью!).
- **Баланс**: симметрия→Redundancy (надёжность), асимметрия→Reachability (гибкость); fu≈0.36–0.53 → смещение к Redundancy; парные дают ~65% Redundancy.
- **Модульность**: **фибрации = изоморфные входные деревья** → кластеры синхронизации (подтверждено ODE-симуляциями); моторные нейроны — **самый похожий класс** (scRNA).
- **Сети**: CeH0 280/2895, CeH2/H3 180/1669/1633, CeMc (самец) 358/3195, CeMe (эл.) 317, стадии L1–L3 161–174; в анализ включена и личинка дрозофилы (пара!).
