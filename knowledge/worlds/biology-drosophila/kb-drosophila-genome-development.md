# Слой 1 — Геном и развитие (biology.drosophila)

**world-id:** `biology.drosophila` · **Слой:** 1/7 · **Статус:** каркас-инвентаризация (2026-09-19)

## Что покрывает слой

Как из генома вырастает нервная система дрозофилы: генетический аппарат, программа развития (сегментация, детерминация), нейрогенез (нейробласты, гемилинейджи), метаморфоз, детерминация пола. Вопрос слоя: **какие генетические механизмы производят нервную систему, чей полный чертёж у нас есть (слой 3)?**

## Известные вехи (каркас — проверять по источникам)

### Генетика и геном
- Drosophila melanogaster — модельный организм; Т. Х. Морган (1910-е): хромосомная теория наследственности, сцепление, мутант white
- Геном: ~180 Mb, 4 пары хромосом, ~13–14k генов; полный геном секвенирован (2000, Adams et al., *The genome sequence of Drosophila melanogaster*, Science) — точные цифры проверить
- База: **FlyBase** (flybase.org) — геном, гены, фенотипы, экспрессия

### Программа эмбрионального развития
- Нобелевская премия 1995: Э. Льюис, К. Нюсляйн-Фольхард, Э. Вишаус — генетический контроль сегментации
- Каскад детерминации сегментов: материнские эффекты (bicoid, nanos) → гэп-гены (hunchback, Krüppel, knirps) → pair-rule (even-skipped, fushi tarazu) → сегмент-полярность (engrailed, wingless, hedgehog) → гомеотические (Hox: Antennapedia complex, Bithorax complex)
- Гомеобокс, Hox-коллинеарность, Hox-гены как позиционные идентификаторы

### Нейрогенез
- Нейробласты делятся стереотипно; клеточные линии → **гемилинейджи** (половина линии, единицы идентичности)
- Типы нейронов кодируются генетически: клеточная идентичность → спецификация связей (связь со слоями 2–3)

### Детерминация пола и диморфизм
- Каскад: X-соотношение → sex-lethal → transformer → doublesex / fruitless
- fruitless/dsx — основа поведенческого диморфизма (ухаживание, агрессия) — связь со слоями 5–6
- MCNS (мужской CNS-коннектом) — полный диморфный чертёж (слой 3)

### Метаморфоз
- Личинка → куколка → имаго; имагинальные диски; экдизон/ювенильный гормон
- Нервная система взрослой мухи — из личиночных нейронов + новых имагинальных

## Дополнение (2026-09-19, раунд 19) — генетическая трассировка (гены → структура)

### Гемилинейджи: генетический чертёж прослеживается в коннектоме
- **259 гемилинейджей** (линии нейробластов) порождают CNS (данные: BANC meta, 50 501 аннотированных)
- Крупнейшая линия — **MBp (4 552 нейрона) = грибовидное тело** — генетическая линия, создающая весь обучающий модуль (связь со слоями 4–5!)
- Регионально: central_brain 207 линий / 32 888 нейронов; VNC 60 / 14 143; optic_lobe 34 / 3 470 (optic нейрогенез вне классической гемилинейдж-таксономии)
- **Закон 5 подтверждён на уровне линий:** клеточные типы = продукты конкретных нейробластных линий (генетические программы → структурные группы)

### Половые генетические программы (данные)
- **fru/dsx: ~5 000 нейронов** (♂ MCNS: fru_high 2 611, fru_low 1 989, dsx 154, coexpr 258) — генетически «половые» нейроны
- **Диморфизм: ♀ BANC — dimorphic 2 862 + female-specific 946; ♂ MCNS — male-specific 1 258 + dimorphic 771** — ~1–2% специализированного полового меньшинства (методологии разные, прямое сравнение некорректно)
- Трассировка: sxl→tra→dsx/fru (каркас слоя 1) → fru/dsx-экспрессия (данные) → диморфные цепи → поведение ухаживания (слой 5) — полный путь «ген→структура→поведение» прослежен

## Дополнение (2026-09-19, раунд 1 углубления) — трассировка «линия → тип → функция» подтверждена

### MBp-линия = весь грибовидный модуль (Kenyon-клетки)
- MBp (4 552 нейрона) = **только Kenyon-типы**: KCg-m 1 456, KCab 1 336, KCa'b' 473, KCg 441, KC 433, KCg-d 155, KCab-p 81, KCapbp-* 122... — **одна нейробластная линия порождает весь обучающий модуль** (подтверждение: «линия → модуль», закон 5)

### Зрительные проекционные линии → конкретные типы
- **VPNv1 → LC17** (332), **VPNd2 → LC10a/LC10d/LC10c**, VPNv2 → LC16, VPNp2 → LC18, VPNd1 → LPLC2, VPNd3 → LC9, VPNp3 → LC11 — VPN-линии дают конкретные LC-проекционные типы (гены → тип → проекционная функция)

### AN/DN происходят из конкретных линий
- **descending**: putative_primary 386 (большинство DN), LB7 129, LB12 106, MX3 96, MX12 92
- **ascending**: 08B 240, 07B 230, 05B 183, 10B 180, 09B 133, 19B 125 — **AN-линии = B-линии 05–19**
- **Хабы ↔ линии**: DNc01, DNb05, MeLp1 — putative_primary; **AN19B001 — линия 19B** (имя типа = линия!) — хаб потока генетически из линии 19B

### Вывод для синтеза
- **Трассировка генетики полная**: нейробластная линия (геном) → клеточные типы (развитие) → функциональный модуль/хаб (коннектом) → поведение (слой 5). Закон 5 — не абстракция, а прослеженный путь
- MB = генетически выделенный модуль (одна линия) — закон 4 («обучение как отдельный модуль») получает генетическое основание: модуль не просто функционально обособлен, он **онтогенетически обособлен** (своя линия нейробластов)
- AN/DN-хабы — из малого числа линий (LB/MX/B-линии) — «малые вентили» генетически запрограммированы

## Дополнение (2026-09-19, раунд 2 углубления) — MB = ансамбль генетических линий

### Трассировка MB-модуля (MCNS аннотации, itoleeHl)
| Компонент | Нейронов | Линии (itoleeHl) |
|-----------|----------|------------------|
| Kenyon (KC) | 4 064 | **MBp1 (996), MBp2 (1012), MBp3 (1038), MBp4 (1018)** — 4 под-линии MBp |
| DAN (дофаминовые «учителя») | 340 | **CREa2_medial (175), CREa1_dorsal (141)**, putative_primary (24) |

- **MB = НЕ одна линия, а ансамбль**: KC из MBp (4 под-линии), DAN из **CREa1/CREa2** (отдельная генетическая линия!), MBON из нескольких (putative_primary, DL1, FLAa2, EBa1, SMPad3)
- **«Учитель» (DAN) генетически отделён от «ученика» (KC)** — подкрепление как отдельная линия CREa — закон 4 подтверждён генетически
- **DAN: fru_low у 245 из 340 (72%!)** — дофаминовые «учителя» сами fru-экспрессирующие — связь половой генетики с обучением (ухаживание-специфическое подкрепление — гипотеза для слоя 5)
- BANC: MBON* 104, PAM* 281 (DAN), PPL* 21, KC* 4 552 — согласуется

### Уточнение трассировки
- MBp = KC-линии (все KC-типы), но модуль MB включает ещё CREa (DAN) и смешанные линии (MBON) — **функциональный модуль = несколько генетических линий**
- KC-под-линии MBp1–4 → KC-подтипы (KCg-m, KCab-s/m/c...) — одна линия, но под-линии дают подтипы (каскад делений нейробласта → разнообразие KC)

## Дополнение (2026-09-19, раунд 6 углубления) — механизм «одна линия → много типов» найден

### Проверено (PubMed)
- **Cachero, Jefferis, Donà et al., Nature 2026** (DOI 10.1038/s41586-026-10797-w): «**A global molecular code for birth order and neuronal identity in Drosophila**» — **глобальный молекулярный код порядка рождения нейронов** (birth order) определяет нейронную идентичность — **это механизм, который я искала**: как одна нейробластная линия (MBp1–4) порождает множество типов (KCg-m/KCab/...): **порядок делений кодируется молекулярно** (временна́я транскрипционная программа нейробласта)
- **Bakshi, Desplan et al., Curr Opin Neurobiol 2025** (DOI 10.1016/j.conb.2025.103061, review): «Decoding neuronal diversity: Mechanisms governing neural cell fate in Drosophila» — обзор механизмов судьбы нейронов (proneural → temporal identity → terminal)

### Закрыт открытый вопрос (раунд 1/2 углубления)
«Как одна линия порождает множество типов?» → **ответ: молекулярный код порядка рождения (Nature 2026)** — нейробласты проходят временну́ю программу, каждый раунд деления даёт разные типы (temporal identity). Это завершает трассировку: геном (линия) → временной код (birth order) → типы → структура.

### Что это значит для синтеза
- **Закон 5 уточнён**: структура задана не только «какой линией», но и «когда в линии» (temporal identity) — генетическая детерминация включает время развития
- **Трассировка генетики полная**: sxl→tra→dsx/fru (пол) + proneural→temporal→terminal (идентичность) — два кода определяют типы
- Связь с данными: MCNS birthtime (early 7 891 / late 13) — подтверждает временну́ю структуру (нейроны рождаются в разные фазы)
