# Reference-сводка: как работает Drosophila melanogaster («лего-инструкция») v1

## Назначение
Полная инженерная сводка «как это устроено» — от генома до поведения — на основе всего собранного (карточки evidence + BANC-анализ + функциональная глубина F1–F6 + сравнительный). Цель: единый reference для последующей CASA-реорганизации.

**Мир:** biology.drosophila · **Дата:** 2026-09-19 · **Статус:** v1 (синтез; ссылки на карточки в каждом слое)

## Слой 0 — Геном: НЕ схема, а «код + материалы»
- ~180 Mb, ~14k генов; энхансеры/регуляторные модули = конфигурационная логика.
- **Кодируется**: ТФ (коды идентичности), NT-синтез/транспорт (классы), рецепторы, морфогены, структурные белки.
- **НЕ кодируется**: схема связей. Связи возникают в развитии (детерминированно!).
- Карточка: `kb-drosophila-genome-development.md` (слои 0–1).

## Слой 1 — Развитие: три ортогональных кода → линии
| Код | Механизм | Задаёт |
|---|---|---|
| Позиционный | Hox/сегментация (French Flag, stripe-энхансеры, Zelda/Opa) | сегмент/регион |
| Временной | **17 TF (shTF)** — консервированный порядок (mamo/jim/br, Imp/dati); работает во всём CNS (кроме оптических долей) | подтип (birth order) |
| Половой | sxl→tra→dsx/fru | диморфизм |
- **120 нейробластов/полушарие → 183 гемилинейджа (Notch ON/OFF) → 30 233 нейрона (88%)**; неаннотированные — первичные (~10%).
- Две волны: **первичные (Imp, эмбрион)** vs **вторичные (dati, личинка)**; ранние-вторичные — тоже Imp+.
- **Метаморфоз**: один геном → два мозга (личинка/имаго) — «версионирование» (личинка: 3 016 нейронов).
- Сегменты: **122 группы (гемилинейдж × сегмент)**; Hox-уровни — гемилинейдж-специфичны; сложность траекторий ↔ сериальная гомология.

## Слой 2 — Типы: линии → каталог
- **8 453 типа** (консенсус); 120 линий → 183 гем. → типы; транскриптом взрослого = гемилинейджи (8/8); 246 broad → 4 167 подтипов.
- **NT специфицируется в линии** (1 быстрый NT/гем.; исключения — котрансмиссия: VPM4 = OA+Glu; LHON AV2a1/a4 = ACh+GABA).
- **Типы ≠ атомы**: 59% singleton; 32% hemibrain-типов не валидированы; вариация 0.3±1.8 внутри/0.8±10 между.
- Адрес нейрона = (линия × время рождения × сегмент × Notch) × пол; полный trace: 88% нейронов × 94% типов ≈ ~83%.

## Слой 3 — Коннектом: «программа + шум»
- **Сильные рёбра = программа**: 7–16% рёбер = 50–70% синапсов; **53% сильных консистентны между датасетами**; слабые — «снежинка» (>50% уникальны).
- **13 сетей** (спектральная): leg VNC (крупнейшая), L/R visual/olfactory, posterior brain (WED/AMMC/JO), lateral brain (LH), inferior, superior, dorsal VNC, abdominal, flange median bundle; **10/13 > median влияния на эффекторы; CX-связанная и обонятельные — НЕ влияют напрямую**.
- **AN/DN: 3 165 (17 поведенческих кластеров)**; bottleneck выхода: **эффекторы 0.5%** CNS.
- Рекуррентность (личинка): DAN 57%, MB-FBN 51%, MBON 45%, CN 42%, KC 0.1% — **учителя рекуррентны, KC — нет**.
- **Efference copy**: 37% DNsVNC / 66% DNsSEZ → мозг (копия действия → учитель).
- Карточки: `kb-drosophila-connectome-evidence.md`, `kb-drosophila-larva-connectome-evidence.md`, `kb-drosophila-trace.md`.

## Слой 4 — Функциональные модули (как «лего-блоки»)

### 4.1 Сенсорика (параллельные каналы)
- **Зрение**: 732 типа/892 колонки; топографический канал (R7→MeTu→AOTU→EB — навигация) + **нетопографический** (MeTu-m: 3 слоя + коллатераль в лобулу; Bui-супрессия) — «не всё картировано, часть — фильтры»; доменная сегрегация (идентичность доменов > пространство).
- **Обоняние**: AL → PN (uPN/mPN) → LH/MB (KC sparse 4–6/2 000).
- **Механо/слух**: WED/AMMC (WED-PN 1–6, JO-E/B/F) → LH/SPIN.
- **Вкус**: SEZ (GNG-PN, вкусовые сенсиллы) → LH; **термо**: термосенсорные → LH.

### 4.2 LH — мультимодальный узел валентности/контекста
- **44 LHON типа** (26 ACh/13 GABA/9 Glu; 3 двойных NT); 14 LHIN из НЕ-обонятельных областей (WED/LO/GNG/VNC); 165 core-типов (Frechter).
- **BANC-анализ (наш, v888)**: **65.6% LHON мультимодальны** (708/1 080; 33.4% со значимыми ≥3); 199 трёхмодальных (mech+olf+vis); зрение 47%, механо 28%, SEZ 22.5%.
- **LH→DAN: 482 LHON → 94% DAN (PAM+PPL1!)** — врождённая валентность в учителя (оба полюса).
- **LH→CX: 269 LHON; LH→DN: 491 LHON** (расхождение с Dolan — прямые связи с мотором есть!); LH→MB (KC/MBON/MB-DAN).
- **Валентность**: ACh = привлекательное (еда), Glu = отвратительное (токсины/социальное/температура) — оппонентная NT-логика.
- Карточка: `kb-drosophila-lateral-horn-evidence.md`.

### 4.3 SPIN — bottleneck валентности («автоэнкодер»)
- SPIN = >85% синапсов в SP (1 411 hemibrain / 2 844 FlyWire); **LHON→SPIN many-to-one; SPIN→FBt one-to-many; MBON→SPIN many-to-many; OPN→SPIN one-to-one**.
- **75% SPIN — ингибиторные/модуляторные; GluClα — доминирующий рецептор** (глутамат = ингибирование!).
- **SMP353** (ACh, attractive): LHON+MBON07/14 (LTM!) → **FBt layer 6** + DANs + модуляторы; **дендритные компартменты** (вход/выход разделены); **shunting inhibition (GluClα) = мультипликативное торможение → coincidence/AND**; приоритеты: innate aversion > attraction; learned > innate; социальное подавляет foraging (арбитраж).
- **SIP015** (Glu, aversive): зеркальный; механо WEDPN3/6A/12/8C → LHPD2d1 → SIP015.
- Карточка: `kb-drosophila-spin-valence-evidence.md`.

### 4.4 MB — ассоциативное обучение (TD-подобное)
- KC sparse (4–6/2 000; APL-ингибирование); MBON (~35 типов); **DAN = учитель** (отдельная линия CREa).
- **Prediction-error-петля** (g1→g5 + DA feedback; насыщение + extinction) — **TD-подобно**.
- **Память = субклеточный компартмент** (MBON-γ1pedc; LTD-подобное ↓веса KC→MBON).
- **Два трека LTM**: классический (белок, MB, сон — eLife 2015: одна пара нейронов связывает сон с консолидацией) **vs cLTM** (мгновенный, без белка, вне MB — LH!, DA-зависимый, ≥14 дней, холодостойкий).
- Карточки: `kb-drosophila-plasticity-evidence.md`, `kb-drosophila-mushroom-body-evidence.md`.

### 4.5 CX — навигация/решения/рабочая память
- **Ring attractor**: EPG 16 wedges; EB-PB-PEN/PEG; векторная арифметика (FB: базис 4×90°); TV-вектор.
- **FB = goal**: бамп VT062617/h∆K21 (цель), evidence integration (ramping), **персистентность 5–10 с**, **3 состояния (baseline/goal/search)**, **оптимальность к статистике шлейфа** (длительность = оптимум!). Рекуррентность h∆K21↔PFG.
- **Copy-and-shift**: рамки egocentric→geocentric (WPN, рабочая память желаемого направления); **confidence-weighted интеграция** (ring attractor: веса по достоверности, гейты ON/OFF, веса ∝ концентрации).
- **Steering-контроллер**: CPU1 = desired−current (16 нейронов; θM = kmotor·(ΣL−ΣR)) — **П-контроллер**.
- Карточки: `kb-drosophila-cx-coordination-evidence.md`, `kb-drosophila-decision-evidence.md`.

### 4.6 Моторика — делегирование
- MDN → локальные модули: **LBL40** (T3, stance/tibia flexion), **LUL130** (T1–T3, swing/leg lifting); **эпистаз**; кинематика 6 ног × 4 сустава; **обезглавленные работают** (локальные петли, не центральная программа).
- Карточка: `kb-drosophila-motor-evidence.md`.

## Слой 5 — Как это работает вместе (поток информации)

```
Сенсорика (зрение/обоняние/механо/вкус/термо)
   │  параллельные каналы (топо + нетопо)
   ├─→ LH: конвергенция модальностей (65.6% LHON!)
   │      ├─ валентность (ACh+/Glu−) ──→ DAN (94%!) — врождённый учитель
   │      ├─→ CX (269 LHON) — навигационный контекст
   │      ├─→ DN (491 LHON) — прямое действие
   │      └─→ MB (KC/MBON) — ассоциативное кодирование
   ├─→ MB: KC sparse → MBON (TD-подобное; компартмент-память; 2 трека LTM; сон)
   │      └─→ SPIN (learned валентность; MBON→SPIN many-to-many)
   └─→ SPIN: bottleneck (LHON+MBON → скаляр-валентность; GluClα coincidence/AND)
          ├─→ FBt (CX, layer 6) — выбор действия (context-dependent action selection!)
          ├─→ DANs + модуляторы (DA/5HT/OA/пептиды) — глобальное вещание
          └─→ (приоритеты: aversive>appetitive; learned>innate; социальное>еда)
Мотор: DN (через воронку 0.5% эффекторов) → локальные модули (LBL40/LUL130)
       └─ efference copy (37% DNsVNC→мозг) → DAN = учитель (действие→обучение!)
CX: FB (goal, 3 состояния, evidence integration) + ring attractor (heading)
    + copy-and-shift + П-контроллер (CPU1=desired−current) → steering
```

## Инженерные принципы (для CASA) — сводка
1. **Каталог + сильные рёбра** (программа) + слабые (шум/пластичность) — подтверждено на 3 масштабах (C. elegans 39%/2.5%; дрозофила 53%; мышь like-to-like).
2. **Like-to-like** (связность по сходству представлений) — механизм: генетика (насекомые) или Hebbian (мышь) — цель одна.
3. **Воронка выхода** (0.5% эффекторов) + **делегирование** (локальные модули, без центральной программы).
4. **Конвергенция → низкоразмерный скаляр → дивергенция** (SPIN-автоэнкодер: мультимодальность → валентность → вещание).
5. **Оппонентная полярность** (NT = знак: +/−) — единый механизм для innate и learned.
6. **Coincidence/AND-гейт** (шунтовое мультипликативное торможение, GluClα; дендритные компартменты) — контекст-гейт.
7. **Приоритеты зашиты в структуру** (aversive > appetitive; learned > innate) — арбитраж, не планировщик.
8. **Efference copy** (действие → учитель) — IOP-петля подтверждена.
9. **TD-подобное обучение** (prediction-error, насыщение, extinction) + 2 трека LTM (консолидация/сон vs мгновенный/без белка).
10. **Аттракторная рабочая память** (goal-бамп, 3 состояния, оптимум к статистике среды) + **П-контроллер** (error→motor).
11. **Контекст-гейтированный доступ к памяти** (cLTM: AND по модальностям; DA-записанный эталон) — «интуиция».
12. **Метаморфоз/версионирование** (один геном → два мозга) — «переиспользование программы».

## Честные границы
- Механизм AND (физиология) — предложен (GluClα/dendritic), НЕ измерен в поведении.
- cLTM — одна работа (репликация не проверена); структура — 2 независимые (Dolan/Frechter + наш BANC).
- Первичные нейроны (10%) — слабо аннотированы; детали ремоделирования — TODO.
- % полного trace (~83% нейронов) — оценка, не публикация.
- Физиология copy-and-shift — не проверена (модель).
- Мышь/человек — для сравнения; инварианты — на 3 масштабах (302→160k).
