## Reflect — осознание собранного (2026-09-19, раунд 6, после evidence-прохода)

Что изменилось в понимании после 23 evidence-карточек (полные тексты):

1. **«Типы» — не атомы.** 8 453 типа (консенсус), но 59% — singletons, 32% hemibrain-типов не валидированы. «Тип» = устойчивая межмозговая группа (определение Schlegel), с вариацией. Для CASA: онтология — статистическая, не дискретная.
2. **Идентичность = развитие, целиком.** 17 TF кодируют birth order; транскриптом взрослого = гемилинейджи (8/8). «Молекулярная память развития» сохраняется — взрослый мозг читается как продукт программы (два кода: половой + временной).
3. **Архитектура ≠ «сэндвич».** Локальные сенсор→эффектор петли (reafference) + селективные длинные пути через AN/DN (17 кластеров); 13 сетей; subsumption (модуль рекрутирует/подавляет). Супервизоры (MB/CX) — не контроллеры. Для CASA: распределённое воплощённое управление — прямой вызов классике.
4. **Вычислительные примитивы малых сетей.** Ring attractor (16 направлений) + векторная арифметика (FB: базис 4×90°) — «малые рекуррентные сети с аттракторной динамикой» — реальный, не абстрактный механизм.
5. **Мотивация = арбитраж, не триггер.** Пептидные состояния (DILP/Upd2/AKH/NPF), сенситизация периферии, DA-WED (белок vs сахар — конкуренция!), MB-интеграция. Сон — «потребность», отдельная от памяти.
6. **Ограничения моделей.** Котрансмиссия (нейрон ≠ 1 NT) и слоёное ингибирование (авторецепторы/Rdl) — контроль поведения через тормоза. GJ — настраиваемые быстрые каналы (Frazzled).
7. **Эволюция: стабильный каркас + пластичный репертуар.** Hox/17TF/FB/OA консервативны; песня/половой отбор — изменчивы и под отбором (QST>FST).

Честные границы (не переносить без проверки): линейная «influence» (не динамика), 9.3% функций AN/DN известны, полный коннектом — только D. melanogaster, FCA (OA:N) — данные без полного текста, LTP/LTD — слой 5 (частично), генетика сна — TODO.

Осознание для CASA-сверки (предварительно, до сравнения): природа реализовала «innate catalog» (генетически заданные типы/цепи) + локальное обучение (MB) + распределённое управление (петли, модули) + потребности с арбитражем. ЭТО — опора для сверки; сама сверка — вне этой цели (по запросу).

## Active Guardrails

- Порядок строгий: объект (дрозофила) как он есть → потом CASA; никаких «вдохновений по мотивам» до завершения синтеза.
- Честность: «проверено» = карточка с источником; непроверенное — явно (TODO/uncertainty); «не найдено/противоречие» фиксируется.
- `worlds/` — публичный слой: без машинных путей (`D:\…`), без ссылок на `work/`, без scope; авторство агентов — сохраняется.
- Не эмулируем муху: синтез = понимание, не симулятор.
- Полные тексты (не абстракты) — для фундаментального прохода; скрининг по заголовкам — только отбор кандидатов.
