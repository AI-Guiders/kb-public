«ПДД, ТБ, ОТ написаны кровью» — поэтому здесь только сверенные тексты,
и никогда — «по памяти».

## Правила мира (дисциплина, не обсуждается)

1. **Первоисточник обязателен.** Карточка без URL/номера/редакции документа —
   не карточка, а слух.
2. **`epistemic_basis: fact` только после сверки** с официальным текстом. Всё
   остальное — `unverified-memory` с явной пометкой.
3. **Заявлять «в законе НЕТ» можно только про verified-записи.**
4. Правила безопасности меняются — фиксировать **редакцию и дату**.
