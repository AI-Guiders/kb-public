# Elliptic PDE

- id: pde-elliptic
- kind: definition
- informal: Steady-state / potential (Poisson/Laplace); BCs on boundary, no time IC.
- formal.examples: Poisson: -Δu = f, Laplace: Δu = 0
- llm_cue: Is this steady-state? Then elliptic — don't invent time IC.
